# Inventory Management System — Week 1 Architecture Design

This repository contains the Week 1 planning and architecture design for a Java-based Inventory Management System designed for a small retail business.

## Project Overview

The proposed system is designed to manage products, categories, suppliers, inventory, customer orders, stock transactions, and business reports.

The architecture follows a layered modular approach using:

* Java
* Spring Boot
* REST API
* MySQL
* JPA
* Dependency Injection

## Week 1 Deliverables

* Project requirements analysis
* High-level system architecture
* Module design
* Database design
* REST API planning
* Design pattern selection
* Java code scaffolding
* Business workflow design
* Validation and exception-handling strategy
* Testing strategy
* Security and future enhancement plan

## Architecture

The proposed system is divided into:

1. REST API / Controller Layer
2. Service / Business Layer
3. Repository / Data Access Layer
4. Database Layer

The main functional modules are Product Management, Stock Control, Order Processing, Reporting, Supplier/Category Management, and Audit/Inventory Transactions.
